# Thư mục THAM KHẢO (không hỗ trợ)

Đây là các script của **luồng cũ** (form→base→Meta một phát, dựng Nhóm QC/tệp cứng) đã được
luồng chuẩn **Bảng 0 → buoc2 → buoc3 → agent-3x** thay thế. Giữ lại chỉ để bạn đọc tham khảo ý tưởng.

- Token/ID riêng đã được thay bằng placeholder `<...>` — **các script này KHÔNG chạy được nguyên trạng**.
- ⚠️ Lưu ý: biến `T2` ở đây trỏ bảng **Nội dung**, khác `T2` (Nhóm QC) ở luồng chuẩn. Đừng trộn lẫn.

👉 Để triển khai thật, dùng các script ở thư mục cha (`../`) cùng `config.env`.
